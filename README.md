# Team4 – The Zen Of Five Python Hackathon

## 📌 Project Overview

This repository contains our **Python Hackathon project** focused on analyzing a healthcare dataset using Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, and Machine Learning.

The project follows the complete data-analysis workflow:

- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Analysis
- Machine Learning
- Model Evaluation
- Insights and Conclusions

## 📊 Dataset

The project uses the **Heart Failure / Hospital Clinical Dataset**.

The dataset contains patient and hospital-related information that can be analyzed to identify patterns and factors associated with patient outcomes.

Dataset source:

[PhysioNet – Heart Failure Dataset](https://www.physionet.org/content/heart-failure-zigong/1.3/)
